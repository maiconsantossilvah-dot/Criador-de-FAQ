# Aba Bento

Arquivos oficiais da aba Bento grid.

- `bento.html`: HTML base do layout.
- `bento.css`: CSS de saida do layout, sem estilos globais de demo como `body` e `.demo-shell`.
- `bento.js`: modulo carregado pela pagina de Qualidade Conteudo e usado pelo core do Layout Lab.

Fonte visual inicial: `bento-grid-section.html` na raiz do projeto.
