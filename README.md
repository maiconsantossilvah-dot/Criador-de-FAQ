# Layout Lab

Aplicacao estatica para montar layouts de conteudo, gerar blocos HTML/CSS e publicar pelo GitHub Pages.

## Para usar

Abra `index.html` ou acesse o link publicado no GitHub Pages.

- `Qualidade Conteudo`: layouts, guias, FrameWork, FAQ, tabela, stories, artigo, carrossel e bento.
- `Qualidade Tecnica`: gerador de FAQ tecnico mais enxuto.

## Para publicar

A pasta pronta para subir fica em:

```text
00_PUBLICAR_GITHUB/
```

Suba o conteudo dessa pasta no repositorio do GitHub Pages.

## Documentacao da equipe

Comece por:

```text
00_GUIA_EQUIPE/COMECE_AQUI.md
```

Arquivos importantes:

- `00_GUIA_EQUIPE/PUBLICAR_GITHUB.md`: o que subir e o que nao subir.
- `00_GUIA_EQUIPE/ONDE_MEXER.md`: onde alterar cada parte do app.
- `00_GUIA_EQUIPE/TREINAMENTO_15_MIN.md`: roteiro rapido para treinar alguem.

## Regra rapida

Se mudar HTML, CSS ou JS do app, copie a versao atualizada para `00_PUBLICAR_GITHUB/` antes de subir.

Se trocar imagem ou asset, suba tambem a pasta `assets/`.
