# CSS estrutural do Layout Lab

Estes arquivos concentram somente a estrutura duravel de cada layout.

- Carregue `base.css` antes do CSS do layout.
- Cor, gradiente, opacidade, texto, imagem e ajustes feitos na previa devem permanecer no HTML como estilos inline ou variaveis CSS inline.
- Os arquivos nao carregam estilos do editor, contornos de selecao, alcas de resize ou elementos de bastidor do Layout Lab.

Arquivos disponiveis:

- `faq.css`
- `tabela.css`
- `stories.css`
- `artigo.css`
- `carrossel.css`
- `bento.css`
