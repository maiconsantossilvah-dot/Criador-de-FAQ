# O que subir no GitHub Pages

Suba estes itens da raiz do projeto:

- `index.html`
- `qualidade-conteudo.html`
- `qualidade-tecnica.html`
- `assets/`
- `favicon.ico`, `favicon.png` e `favicon.svg`, se quiser manter os favicons no repositorio
- `README.md`, opcional

Nao precisa subir:

- `90_ARQUIVO_LOCAL/`
- `00_PUBLICAR_GITHUB/`
- `.agents/`
- `.git/`

Regra simples: a raiz limpa e a pasta `assets/` sao o app. A pasta `90_ARQUIVO_LOCAL/` e so arquivo de apoio, teste e historico.
