# FAQ

Esta pasta agrupa os arquivos da aba FAQ para ficar mais facil localizar e editar o layout.

- faq.html: estrutura HTML de referencia do bloco gerado.
- faq.css: estilos do bloco/output desta aba.
- faq.js: modulo oficial carregado pela pagina antes do core.

Observacao: se a aba quebrar, procure primeiro neste arquivo JS. O core fica em assets/js/layout-lab.js e deve cuidar apenas da orquestracao geral.
